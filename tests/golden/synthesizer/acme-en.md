## Overview

Acme Cloud presents a light interface built on a bright white canvas (`{colors.canvas}` — #ffffff). Primary text is cool near-black (`{colors.ink}` — #0f172a).

Actions use a single accent: indigo `{colors.primary}` — #4f46e5 on button-primary. Type is set as Space Grotesk headings with Inter text. Weights range from 400 to 700. The shape language uses moderately rounded corners (most common radius 6px). Elevation relies on subtle shadows (levels: 2).

### Key Characteristics

- Canvas: bright white `{colors.canvas}` — #ffffff; text `{colors.ink}` — #0f172a
- Actions: a single indigo accent (#4f46e5)
- Typography: Space Grotesk headings with Inter text; JetBrains Mono for code; weights 400, 500, 600 and 700
- Shape: moderately rounded corners (most common radius 6px)
- Depth: subtle shadows (levels: 2)
- Spacing: 4px base unit; container up to 1200px
- Responsive: the top nav collapses to a hamburger below 1024px
- Dark theme: captured (dark canvas #0b1020)

## Do's and Don'ts

- Do reserve `{colors.primary}` — #4f46e5 for the main call to action and accents (button-primary, button-ghost, text-link and badge).
- Do set running text in `{colors.ink}` — #0f172a on `{colors.canvas}` — #ffffff (17.85:1).
- Do set headlines in `{typography.display}` — Space Grotesk 64px / 700 / 1.05 and body copy in `{typography.body}` — Inter 16px / 400 / 1.6.
- Do keep spacing on the 4px grid, e.g. `{spacing.xs}` — 8px, `{spacing.sm}` — 12px, `{spacing.xl}` — 24px and `{spacing.xxl}` — 32px.
- Do keep each component on its measured radius: `{rounded.md}` — 8px for button-primary, button-secondary, button-outline and button-ghost; `{rounded.sm}` — 6px for nav-link and text-input; `{rounded.xl}` — 16px for card.
- Do reproduce the measured hover states — button-primary: background → #4338ca; button-secondary: background → #1e293b.
- Do limit elevation to the measured shadow levels: sm on button-primary and input; md on card.
- Do collapse the top nav into a hamburger menu below 1024px.
- Don't set `{colors.faint}` — #94a3b8 text on `{colors.canvas}` — #ffffff: it measures only 2.56:1 (caption), below WCAG AA 4.5:1. Use `{colors.muted}` — #475569 (7.58:1) for small text instead.
- Don't set `{colors.success}` — #16a34a text on `{colors.canvas}` — #ffffff: it measures only 3.30:1 (inline success note), below WCAG AA 4.5:1. Keep it for icons, borders or large text, or adjust its lightness until it reaches 4.5:1.
- Don't use `faint` #64748b on `surface-inverse` #05070f in the dark theme: it measures only 4.23:1 (footer copyright), below WCAG AA 4.5:1. Acceptable only for large text (≥ 24px, or ≥ 18.66px bold).
