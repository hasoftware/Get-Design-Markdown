# Get-Design-Markdown

Công cụ dòng lệnh trích xuất ngôn ngữ thiết kế (màu, typography, spacing, components…) của
một trang web và xuất ra `DESIGN.md` theo spec DESIGN.md của Google Labs, để AI coding agent
tạo UI theo phong cách tương tự. Mục đích: tham khảo, học hỏi phong cách.

> Đang phát triển — hướng dẫn đầy đủ sẽ được viết ở giai đoạn hoàn thiện.

```bash
uv sync
uv run gdm --help
```
